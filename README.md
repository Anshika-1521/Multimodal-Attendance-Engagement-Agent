# Multimodal Attendance & Engagement Agent

## Overview

An AI-powered attendance and engagement monitoring system built using Python, Flask, and OpenCV. The application detects faces through a webcam, records attendance, and displays attendance history through a web dashboard.

## Features

* Live webcam access
* Face detection using OpenCV
* Automatic attendance logging
* Date and time-based attendance records
* Attendance history dashboard
* Basic engagement score demonstration

## Technologies Used

* Python
* Flask
* OpenCV
* HTML, CSS, JavaScript
* CSV for attendance records

## How to Run

1. Clone this repository:
   `git clone https://github.com/Anshika-1521/Multimodal-Attendance-Engagement-Agent.git`

2. Open the project folder:
   `cd Multimodal-Attendance-Engagement-Agent`

3. Install dependencies:
   `pip install flask opencv-python numpy pandas pillow`

4. Start the application:
   `python app.py`

5. Open your browser and visit:
   `http://127.0.0.1:5000`

## Project Status

Prototype developed for the Generative AI with Google Cloud program. The engagement score is currently a basic demonstration and does not represent a validated measurement of student engagement.

## Privacy

Use the camera only with the consent of the people being recorded.
